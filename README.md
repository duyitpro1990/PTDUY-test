# Simple Sum Application

A full-stack application that calculates the sum of two numbers, built with **Node.js (Express)** and **Vue.js 3 (Vite)**.

## 🚀 Prerequisites

- Node.js (v14 or later)
- npm (Node Package Manager)

## 🛠️ Installation & Usage

This project is divided into two parts: `server` (Backend) and `client` (Frontend). Please follow the steps below to run them.

### 1. Start the Backend (API)

Open your terminal at the root folder:

```bash
cd server
npm install
npm start

### 2. Start the Frontend (CLIENT)
cd client
npm install
npm run dev
